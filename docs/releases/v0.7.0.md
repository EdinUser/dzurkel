Dzurkel 0.7.0 adds audio, formatted-document and e-book previews. Select a file,
press Space, inspect its content and close the preview.

### Changes

- Audio playback with play/pause, seeking, volume/mute and available track metadata.
  Supported formats depend on the installed Qt media backend and codecs.
- DOCX and RTF previews with readable text and basic formatting. Legacy DOC uses
  the optional, already-installed `antiword` extractor for text-only previews.
- DRM-free EPUB, FB2 and Chitanka SFB previews, plus common unencrypted MOBI 6
  files using PalmDOC compression or uncompressed text.
- Formatted Markdown with headings, lists, emphasis, code and simple tables.
- Clearer heading hierarchy, list indentation and paragraph spacing. Simple DOCX
  text colors are retained when they have readable contrast against the theme.
- Portrait defaults for document, e-book, Markdown and plain-text previews.
  Text zoom changes content size inside the window; PDF/table sizing, compact
  audio previews and natural image sizing retain their existing behavior.
- A shorter legacy-document footer: **DOC · Text-only preview**.

### Scope and limits

These are bounded content previews. Exact page layout, editing, annotations,
bookmarks and reading-progress management are omitted. Unsupported formatting
retains readable text where possible. Large documents show a labelled partial
preview. DRM-protected/encrypted content shows an error when extraction is
unavailable; Dzurkel does not unlock it.

MOBI support stays deliberately small: no HUFF/CDIC compression, standalone KF8,
AZW/AZW3 or KFX. FB2/MOBI images use placeholders, and complex tables become text.
No office suite, Calibre or additional e-book decoder is required.

### Downloads

Choose the runtime installer for your distribution. Package managers resolve
runtime dependencies. Downloads appear after the package/test pipeline passes.

| System | Installer |
| --- | --- |
| Fedora 44, x86_64 | `dzurkel-0.7.0-1.fc44.x86_64.rpm` |
| Debian 13, amd64 | `dzurkel_0.7.0-1_amd64.deb` |
| Current Arch Linux, x86_64 | `dzurkel-0.7.0-1-x86_64.pkg.tar.zst` |

```bash
# Fedora
sudo dnf install ./dzurkel-0.7.0-1.fc44.x86_64.rpm

# Debian 13
sudo apt install ./dzurkel_0.7.0-1_amd64.deb

# Arch Linux: update first, then install
sudo pacman -Syu
sudo pacman -U ./dzurkel-0.7.0-1-x86_64.pkg.tar.zst
```

Download `SHA256SUMS` alongside your installer and verify with
`sha256sum --check --ignore-missing SHA256SUMS`. Packages are unsigned;
checksums verify integrity and are not signatures.

Open **Dzurkel Settings** to enable or restore the optional file-manager
integration. Upgrading does not reassign shortcuts. Dolphin Space setup requires
26.04 or newer. Nautilus and Thunar support retain their existing scope.

Quit and remove a user-local development installation's managed executable and
launchers before installing a system package, so it does not shadow that package.
Keep preferences and integration backups. See the
[installation guide](https://github.com/EdinUser/dzurkel/blob/v0.7.0/docs/installation.md)
and [supported formats and limits](https://github.com/EdinUser/dzurkel/blob/v0.7.0/docs/previews.md).
