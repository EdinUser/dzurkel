# Dzurkel 0.9.0 — Folder information and KDE dialog previews

**Status:** release validation passed, all three runtime installers and
`SHA256SUMS` are attached, and 0.9.0 has been promoted to latest stable.

## Changes since 0.8.0

- Folder previews show contents size and file/subfolder counts asynchronously,
  replacing the misleading directory-entry size, often 4 KiB. Progress, Stop,
  partial results and a 30-second deadline keep slow calculations explicit.
- Optional desktop calculators reuse KIO on KDE and GIO on GNOME/XFCE. Older
  KIO counters that include directory metadata are excluded. Missing or
  incompatible modules leave basic folder information and other previews usable.
- Thunar's Space and context-menu action supports one selected local file or
  folder. Existing managed setups offer **Update folder previews…** in Settings;
  migration preserves original restore backups, shortcuts and unrelated actions.
- An optional KDE file-dialog adapter adds Space previews to compatible native
  `KFileWidget` choosers, including KDE portal dialogs used by applications.
  Enable its separate session-wide opt-in in Settings and sign out/in.
  Caller ownership and focus/dismissal handling keep chooser previews scoped
  to the dialog that opened them.
- Additional media tests cover source failure, recovery and cancellation. Test
  SFTP preferences are isolated from the developer's normal settings.
- Documentation now includes a clearer setup/compatibility guide and a video
  demonstration recorded with 0.8.0; video playback itself was added in 0.8.0.

## Validation and limits

The [0.9.0 release workflow](https://github.com/EdinUser/dzurkel/actions/runs/39417990306)
passed Fedora GCC/RPM and Clang tests, Debian and Arch package builds, all three
clean install/launch/removal checks, the Debian 12 baseline and native GNOME
Wayland/Nautilus input, focus and rendered-placement checks. The attached
runtime installers were downloaded and verified against `SHA256SUMS` before
stable promotion. These gates do not establish every desktop or backend case.

Fedora KDE's folder implementation was smoke-tested by the user. Ubuntu GNOME
passed 27 suites; the Arch package passed 30 suites and fresh-runtime checks
without KIO/CoreAddons. Both VM installations displayed exact generated folder
totals in native sessions. Normal-session Thunar folder Space/Escape passed
after upgrading its existing managed action. The optional-adapters-off baseline
passed 21 suites. These VM builds preceded the final 0.9.0 version bump; see
the [testing record](https://github.com/EdinUser/dzurkel/blob/v0.9.0/docs/testing.md)
for the final source checks. After the version
bump, the local all-adapters build passed 30/30 suites and the baseline passed
21/21; both executables report 0.9.0.

GIO and KIO retain their desktop APIs' different link/count semantics. GIO counts
hard-link entries separately and symlink text without following targets; its
measurement excludes nested filesystem mounts. No custom recursive scanner,
filesystem snapshot or persistent size cache is introduced. Real-share timing,
authentication, disconnection and cancellation still need targeted acceptance.

KDE dialog coverage depends on applications loading the optional Qt adapter.
It does not establish support for every chooser, toolkit or desktop, and stock
GNOME/GTK choosers are not covered by that adapter. The user previously confirmed
the Fedora KDE adapter smoke test; browser upload dialogs were not retested in
the folder-sizing VM run.

## Upgrading

The validated assets are attached to the
[GitHub release](https://github.com/EdinUser/dzurkel/releases/tag/v0.9.0):

| System | Installer |
| --- | --- |
| Fedora 44, x86_64 | `dzurkel-0.9.0-1.fc44.x86_64.rpm` |
| Debian 13, amd64 | `dzurkel_0.9.0-1_amd64.deb` |
| Current Arch Linux, x86_64 | `dzurkel-0.9.0-1-x86_64.pkg.tar.zst` |

Download `SHA256SUMS` alongside the installer and run
`sha256sum --check --ignore-missing SHA256SUMS`. Packages are unsigned;
checksums verify integrity and are not signatures. Follow the
[installation guide](https://github.com/EdinUser/dzurkel/blob/master/docs/installation.md)
for your package manager's commands.

Quit the resident process before replacing the executable and matching adapters.
Folder calculation needs no login opt-in; KDE dialog integration does.
Existing Thunar users should apply **Update folder previews…** in Settings,
finishing file operations before accepting a restart. Installation alone does
not change shortcuts.

See [folder behavior](https://github.com/EdinUser/dzurkel/blob/v0.9.0/docs/folder-previews.md),
[KDE file dialogs](https://github.com/EdinUser/dzurkel/blob/v0.9.0/docs/file-dialog-previews.md),
[Thunar setup](https://github.com/EdinUser/dzurkel/blob/v0.9.0/docs/thunar-integration.md)
and [release validation](https://github.com/EdinUser/dzurkel/blob/master/docs/releasing.md).
