Preview images, PDFs, text and CSV/TSV/XLSX spreadsheets with Space in Dolphin,
Nautilus (Files) and now Thunar.

### Downloads

Choose the installer for your distribution; the package manager resolves runtime
dependencies. These are normal application packages. Debug packages, development
helpers and build metadata are excluded from this release's downloads.

| System | Installer |
| --- | --- |
| Fedora 44, x86_64 | `dzurkel-0.6.2-1.fc44.x86_64.rpm` |
| Debian 13, amd64 | `dzurkel_0.6.2-1_amd64.deb` |
| Current Arch Linux, x86_64 | `dzurkel-0.6.2-1-x86_64.pkg.tar.zst` |

```bash
# Fedora
sudo dnf install ./dzurkel-0.6.2-1.fc44.x86_64.rpm

# Debian 13
sudo apt install ./dzurkel_0.6.2-1_amd64.deb

# Arch Linux: update first, then install
sudo pacman -Syu
sudo pacman -U ./dzurkel-0.6.2-1-x86_64.pkg.tar.zst
```

Download `SHA256SUMS` alongside your installer and verify downloaded files with
`sha256sum --check --ignore-missing SHA256SUMS`. Packages are unsigned; checksums
verify integrity and are not signatures.

### Changes

- Thunar: opt-in Space and right-click previews, desktop detection, reversible
  setup and preservation of existing actions and shortcuts.
- Thunar restart: focus returns once to Dzurkel Settings after Thunar reopens;
  closing or minimizing Settings cancels the pending request.
- GNOME: Nautilus Space preview service and centered adaptive Wayland previews,
  retaining the stable image/document resize and focus behavior.
- Regression protection for Thunar setup/restore and restart focus, plus required
  native GNOME placement, focus and Nautilus keyboard checks in package CI.

After installation, open **Dzurkel Settings** and enable the integration for your
file manager. Installation itself does not reassign shortcuts. Thunar setup
targets one selected local file on XFCE/X11. Dolphin Space setup requires 26.04
or newer. GNOME integration needs no Shell extension or global shortcut.

Before replacing a user-local development install, quit that copy and remove its
managed executable and launchers so they do not shadow the system package. Keep
preferences and integration backups. See the
[installation guide](https://github.com/EdinUser/dzurkel/blob/v0.6.2/docs/installation.md)
and [Thunar setup](https://github.com/EdinUser/dzurkel/blob/v0.6.2/docs/thunar-integration.md).
