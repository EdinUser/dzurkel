# Dzurkel preview demo

- [Full video](dzurkel-demo-0.8.0.mp4) — silent H.264 MP4, 1600 × 900, 30 fps, approximately 36 seconds, at the recorded speed.
- [README animation](../images/dzurkel-demo.gif) — 960 × 540 GIF, 10 fps, at 1.25× speed for a shorter preview.
- [Video poster](../images/dzurkel-demo-0.8.0.png) — a still from the video-playback segment.

## What is shown

The sequence is image → PDF → DOCX → XLSX → video → Python source code, followed
by Escape to dismiss the preview. The video segment shows actual playback.
All sample content and the landscape animation were generated for this
demonstration; no personal documents or third-party footage are shown.

This is a recording of the real Dzurkel 0.8.0 application alongside Dolphin in
an isolated nested KDE Wayland desktop. The initial preview is opened through
the CLI; Alt+Right navigates between files. Window placement and size are arranged
for the recording, and captions are added outside the application windows.
The MP4 retains the recorded timing; it is not a preview-speed benchmark.
The recording remains labelled 0.8.0; it does not demonstrate 1.0.0's progressive
scrolling or text Beginning/End controls. See the [1.0.0 notes](../releases/v1.0.0.md)
for current behavior and validation.

Dolphin is the file manager shown. Existing Nautilus and Thunar integrations are
described in their [setup](../gnome-testing.md) and
[integration](../thunar-integration.md) guides; this recording does not demonstrate
those desktops. Installed backends and codecs still determine media support.

## Sharing

The MP4 is suitable for a YouTube upload or a GitHub video attachment. The main
README uses an inline GIF linked to the repository MP4. For an inline GitHub
video player, [upload the MP4 as an attachment](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)
and use the resulting hosted URL. A YouTube upload can instead be linked from
the GIF or poster. No YouTube upload is included in this repository update.
